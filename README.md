# Arhythmetic

Arhythmetic is a rhythm-based game that focuses on testing your music theory knowledge and reflexes! This game is still in development, but the goal is to create a fun game for people to practice their rhythm accuracy and sight reading skills. Upon completion, the game will allow players to upload their own music and midi files to create custom levels. The game will also include a variety of difficulties, a scoring system based on accuracy and timing, and some main levels to play through. The current preview is written in unity, although I am working on porting the code to Godot. The game will be available primarily on Mac and Linux, but I am working on a Windows build as well.
